# Buy, build or rent for one founder's coding workload

Editorial review draft · 21 November 2026 · Netherlands. Evidence snapshot `nl-2026-11-21.1`.

**Decision:** Hold the approximately €4,500 Thunderobot purchase. For API-led coding agents and bursts of local inference, use the existing developer machine and obtain a small, fixed-budget cloud quote to establish accepted-task cost. For offline or private 48 GB working sets, shortlist AMD unified memory and Apple; pay only after exact-variant, delivered-price, invoice and workload checks. For sustained x86 CUDA work, compare a desktop card in a complete supported system against the cloud after measuring demand.

## One workload, three backend arms

Use Qwen3-Coder-30B-A3B-Instruct GGUF Q4_K_M with an immutable artifact hash, llama.cpp commit and declared context size. Start at 4,096 context and one concurrent request. The 20 GB working-set assumption includes overhead and must be replaced by measured peak memory. Run the same model hash, prompt pack, decoding settings and test oracle on NVIDIA x86 CUDA, AMD x86 HIP or Vulkan and Apple arm64 Metal. Specialized native backends such as MLX may enter a separately labeled arm. [GGUF source](https://huggingface.co/ggml-org/Qwen3-Coder-30B-A3B-Instruct-GGUF) · [AMD ROCm matrix](https://rocm.docs.amd.com/projects/radeon-ryzen/en/latest/docs/compatibility/compatibilityryz/native_linux/native_linux_compatibility.html) · [Apple MLX examples and benchmark tooling](https://github.com/ml-explore/mlx-lm).

## Local and cloud economic test

Use separate wall-clock hours for the same completed-task set. Forecast local gross hardware + actual finance fees + repairs + storage + wall-power × local runtime × tariff − conservative resale. Forecast cloud GPU rate × cloud runtime × dated FX + storage + transfer + taxes. Divide by independently accepted tasks and retain failed attempts in the numerator. Keep money available at purchase separate from net business cost. With €4,500 up front and $0.89/h, the capex-only break-even under **hypothetical** €0.90/USD and equal speed is approximately 5,618 cloud hours, or 234 hours/month over 24 months. That is a quote sensitivity check. Switching to unattended private workloads changes cloud admissibility regardless of price.
